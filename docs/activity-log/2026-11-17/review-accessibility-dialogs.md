- Diálogo de Compras recebe foco inicial e restaura o foco ao ser fechado.
- Tab e Shift+Tab percorrem os controles sem sair do diálogo; Escape fecha a

- `npm run build` e `npm run test:finance` passaram. A prova manual de teclado e
  leitor de tela permanece necessária; REV-14 segue aberta até essa validação.
