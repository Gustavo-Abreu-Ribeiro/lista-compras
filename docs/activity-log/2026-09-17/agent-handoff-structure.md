# Estrutura de retomada inspirada no KofLang

## Contexto

O projeto precisava permanecer compreensível entre sessões e agentes, sobretudo
durante o desenvolvimento do módulo financeiro.

## Mudança

- Adicionado `DOING.md` como handoff operacional curto com um próximo passo e
  prova exatos.
- Separado `docs/development/` para trabalho ativo e
  `docs/development/future/` para intenção ainda não iniciada.
- Conectados README, AGENTS, contribuição, guia de agentes e workboard à nova
  ordem de leitura.

## Limites

A inspiração é documental: não foram adotados cron, automação autônoma ou
ferramentas específicas do KofLang. A fonte de verdade deste produto continua
sendo seu próprio código, contratos e verificações.
