# Identidade visual editorial

- Substituídos gradientes, sombras e excesso de cartões arredondados por uma
  paleta de papel, tinta verde e acento telha, com divisórias simples.
- Navegação móvel e desktop agora compartilham contraste, tipografia e estado
  ativo coerentes; indicadores financeiros usam números tabulares.
- A tela inicial e Finanças tiveram títulos, descrições e atalhos simplificados
  para priorizar dados e ações concretas.

  Argila. Rotas e funcionalidades foram preservadas.
- Verificação: `npm run build` e `git diff --check` passaram. Git mostrou apenas
  avisos de normalização LF/CRLF.
- Validação visual no runtime Tauri não foi executada.
