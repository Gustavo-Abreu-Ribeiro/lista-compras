# Linguagem visual de caderneta e feira

- A marca ganhou um símbolo de cesta desenhado em SVG e o nome Lista de casa.
- A tela inicial usa título editorial, data em etiqueta amarela e uma grade
  assimétrica; o saldo principal recebe destaque de cartaz de feira.
- Linhas tracejadas, contornos de tinta e etiquetas de preço levam a linguagem
  visual também aos painéis e atalhos.
- As paletas alternativas preservam suas cores próprias.
- Verificação: `npm run build` e `git diff --check` passaram. O Git indicou
  apenas avisos de normalização LF/CRLF.
