# Registro de atividades

Este diretório guarda um registro curto por incremento significativo, agrupado
por data. Não é log de execução do aplicativo.

Formato sugerido:

```text
YYYY-MM-DD/descricao-curta.md
```

Cada registro explica o que mudou, por que mudou, como foi validado e o que
permanece fora de escopo.
