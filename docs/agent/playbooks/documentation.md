# Playbook — Documentação

1. Descreva somente comportamento verificado; separe implementado, limite e
   intenção futura.
2. Use a fonte certa: contrato para fronteira pública, arquitetura para estrutura,
   estado para retrato atual, roadmap para intenção e activity log para histórico.
3. Atualize links de navegação afetados.
4. Para decisão difícil de reverter, crie ADR com contexto, decisão, alternativas,
   consequências e status.
5. Revise `git diff --check` e links relativos alterados.
