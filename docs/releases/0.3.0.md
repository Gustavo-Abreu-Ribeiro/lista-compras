# Lista de Compras 0.3.0 — Frutiger Aero

Nova identidade visual completa em **Ajustes → Aparência → Frutiger Aero**,
aplicada em um toque e salva no dispositivo.

- Céu, água e natureza em uma paisagem vetorial local.
- Navegação de vidro com ícones brilhantes, dock móvel e painéis translúcidos.
- Composição própria para início, compras, jogos, finanças, login e ajustes.
- Foco visível, movimento reduzido e layouts conferidos em quatro larguras.
- Feira, Cartucho e as demais aparências continuam disponíveis.

## Downloads e atualização

- **Windows x64:** execute `Lista-de-Compras-Windows-x64-setup.exe`.
  Windows 10/11 com WebView2. Sem certificado comercial Authenticode; pode haver
  aviso de editor desconhecido.
- **Android ARM64:** instale `Lista-de-Compras-Android-arm64.apk`. Android 7 ou
  superior e System WebView atualizado. A assinatura da versão 0.2.0 é
  preservada para permitir atualização sobre a instalação anterior.
- Confira os arquivos com `SHA256SUMS.txt`.

Não é necessário desinstalar nem apagar dados para trocar a aparência. A nova
versão mantém a configuração pública Supabase e não remove a base SQLite legada.

## Validação e limites

Builds Windows/Android automatizados, verificação da assinatura APK e arranque
do executável Windows no CI. QA Chrome com dados fictícios isolados: seis rotas,
seleção/persistência/reversão do tema, modais e formulários em desktop/mobile.
Não foram feitos testes completos em dispositivos físicos. A validação de
CRUD/RLS com duas contas e importação de dados legados continua em CLOUD-001.
Finanças é controle manual, sem Open Finance; preço e estoque exigem conferência
na loja. Nenhuma chave privada ou dado de usuário integra os instaladores.
