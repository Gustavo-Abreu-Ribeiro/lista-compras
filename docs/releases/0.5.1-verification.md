## Site e testes

Na URL pública, `scripts/release/verify-site.mjs` confirmou a abertura nova,
o CSS aplicado e links reais para os dois assets 0.5.1. Localmente passaram
`npm run build`, `npm run test:finance`, `npm run test:pages`,
`npm run test:resume`, `cargo check --locked` e
`node scripts/release/check-version.mjs`. O QA Edge isolado aprovou 52
cenários de UI com dados fictícios e sem acesso à conta real.

## Limites

Não houve prova de CRUD/RLS autenticado, importação SQLite nem teste com
teclado virtual em aparelho real. Nenhuma cópia local foi removida. A release
não exige nova migration; as migrations financeiras citadas em 0.5.0 foram
confirmadas pelo usuário anteriormente, mas os fluxos autenticados seguem
pendentes.
