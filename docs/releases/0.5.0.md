# Lista de Compras 0.5.0

Esta versão traz a gestão de dívidas para uma tela dedicada. O Planejamento
mantém uma visão curta e cadastro rápido; em “Ver todas”, cada dívida pode ser
expandida para consultar e marcar as parcelas mensais. O valor que falta pagar
vem das parcelas pendentes, e a previsão soma compromissos de dívidas diferentes
por mês. Dívidas anteriores, sem parcelas, podem receber um plano.

Também foram melhorados o contraste dos ícones Aero, o resumo financeiro Aero,
os cards Cartucho e a disposição das listas no celular. A carga geral de
Finanças continua disponível quando a atualização de planos ainda está pendente.

## Antes de cadastrar ou converter dívidas parceladas

No SQL Editor do projeto Supabase usado pelo app, execute os conteúdos destes
arquivos, um por vez e nesta ordem:

1. `supabase/migrations/202611170002_financial_debt_installment_plans.sql`
2. `supabase/migrations/202611180001_attach_legacy_debt_plans.sql`

As migrations são aditivas; a segunda disponibiliza a conversão de dívidas
antigas. Ao converter, a recorrência antiga correspondente é pausada e suas
ocorrências ainda previstas são removidas para evitar compromissos duplicados;
gastos já realizados são preservados. A migração não cria parcelas para dívidas
antigas automaticamente: use “Definir parcelamento” na tela de dívidas.

## Validação e limites

Build frontend e Rust, teste financeiro e checks de release devem passar no
CI antes da distribuição. Os instaladores não removem SQLite legado. CRUD/RLS
autenticado e a migração remota ainda exigem conferência no projeto Supabase.
