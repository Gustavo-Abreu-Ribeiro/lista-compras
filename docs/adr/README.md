# Architectural Decision Records

Use um ADR para decisão arquitetural duradoura, mudança incompatível de contrato
ou escolha cuja reversão seja cara. Nomeie os arquivos sequencialmente:

```text
ADR-001-titulo-curto.md
```

Modelo:

```md
# ADR-001 — Título

## Status

Proposto | Aceito | Substituído por ADR-XXX

## Contexto

## Decisão

## Alternativas consideradas

## Consequências
```
